# Reported Defender scan history

The existing Get-MpComputerStatus query now optionally projects quick/full scan start/end timestamps. No additional cmdlet or query is invoked. Existing protection flags and detection-history semantics retain their independent status. Missing, ambiguous, invalid, future, sentinel or unspecified-zone values remain Unknown; explicit-offset and genuine UTC/local timestamps normalize to UTC.

These four fields may describe different scans. Ordering does not establish a current running scan, MadClean ownership, completion, success, scan scope or attributed detections. The UI labels reported history and independent coverage; it never treats old timestamps as a new scan or protection verdict. Raw values are not added to activity logs or validation exports.

Fresh official [Get-MpComputerStatus](https://github.com/MicrosoftDocs/windows-powershell-docs/blob/main/docset/winserver2025-ps/Defender/Get-MpComputerStatus.md), [Start-MpScan](https://github.com/MicrosoftDocs/windows-powershell-docs/blob/main/docset/winserver2025-ps/Defender/Start-MpScan.md) and [Get-MpThreatDetection](https://github.com/MicrosoftDocs/windows-powershell-docs/blob/main/docset/winserver2025-ps/Defender/Get-MpThreatDetection.md) references were checked. Start-MpScan documents scan types but does not establish an engine-owned identifier or sufficient terminal/cancellation/permission contract. A PowerShell job is not an engine scan identity; active/past threat history cannot be attributed to one request. Relevant MpCmdRun documentation requests were denied, so cancellation and remediation-suppression remain unverified, not guessed unsupported.

No scan executor is enabled. Ordinary inspection never starts a scan; killing a metadata-query process must never be reused as scan cancellation. Later explicit QuickScan support still needs verified permissions, trigger side effects, correlation, actual results, user selection and disposable-Windows lifecycle validation. No scan, remediation, elevation or personal-PC action was performed during this increment.
