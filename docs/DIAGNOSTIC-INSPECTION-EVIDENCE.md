# Diagnostics: observations from the current inspection session

The first cross-source Diagnostics report slice reuses the local disk-capacity and Defender status results already returned by **Inspect this PC**. Opening Diagnostics, selecting a row or changing the event time range starts no disk, security or network query. Ordinary inspection still performs no integrity command, malware scan, repair, installation, cleanup or elevation.

The two rows start Unknown with no timestamps or sample values. A new local inspection replaces them with pending observations for that attempt. Each completed source gets its app-recorded UTC attempt and completion time; these are collection times, not proof of when Windows refreshed each field. Completed observations remain while another source fails or is cancelled. Interrupted sources are marked separately, including failure before their loader starts. Rereading replaces the current observation rather than preserving a misleading older success. Online update checks do not refresh these local observations. There is no timer, live-monitor claim, persistence or report export.

Each selected entry explains observation, precise source, scope, uncertainty, possible impact and next step. This is evidence for review, not a scalar health score or a repair recommendation. Available means a source response; Partial retains incomplete coverage. Unknown, failed, unsupported, unavailable and cancelled responses do not contribute plausible-looking result values.

## Minimized source contracts

Storage uses the returned `System.IO.DriveInfo.TotalSize` and `AvailableFreeSpace` metadata, at most64 rows. Only exact drive-letter roots with positive capacity and free bytes within0..capacity are accepted. Duplicate letters are ambiguous even if their values match; invalid rows are omitted with partial coverage, and no valid rows remains Unknown. Free space is caller-visible and may reflect quotas. Volumes can overlap: the report shows per-root byte observations and never sums them into global free space, physical allocation, reclaimable bytes or disk health. It does not diagnose drive failure or predict performance.

Defender requires one returned status record. Only nullable antivirus/real-time/service flags and recognized fixed AMRunningMode labels are retained. Missing flags or an unfamiliar mode remain unknown/partial; arbitrary mode text is not echoed. A disabled/passive observation can reflect policy or another security provider and is not an infection diagnosis. Settings do not establish active protection, absence of threats, a completed scan or overall health. Threat IDs, resource paths, raw messages, versions, signature dates and detection/scan history are excluded from this report. The separate Security source retains its own scope.

Timestamps must be nondefault UTC, ordered and not future; invalid timestamps withhold values and dates. Cancellation is checked before processing and within bounded storage processing. Core projection validates already-returned metadata only; it does not authenticate a fabricated caller object or replace the real Windows provider. Nothing in an entry grants an action or changes execution gates.

## Validation limits

Portable cases cover source-state retention, bounded/ambiguous/invalid drive facts, zero free space, privacy sentinels, recognized/unknown/passive Defender modes, missing/multiple records, timestamp errors and cancellation. The Windows harness has distinct real storage and same-query Defender projection contracts; only fixed states/schema/provenance counts are exported, never capacities, security settings, messages or collection times. Genuine initial tool25 checks binding, two unchecked rows, selection/details and viewport bounds before any provider data is loaded. No later screenshot includes real loaded data.

A separate explicit CI UI workflow uses actual local inspection, selects returned rows through their real grid and checks bound details without another query or log entry. It then requests a reread/cancellation and checks source-specific pending/completed outcomes, with timing races left honest. This does not establish physical input, accessibility, every provider policy or an underlying system-health verdict. Actual source-bound results belong in [the execution ledger](ROADMAP-STATUS.md); compilation is not Windows runtime proof.
