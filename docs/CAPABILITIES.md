# Phase-one discovery and explicit capability queue

The current foundation is preserved and extended with read-only discovery. The prior release-reminder foundation ZIP is retained locally as `artifacts/MadClean-phase1-foundation-576b5ae-win-x64.zip`. Current executable build/run instructions remain in README.md. No cleanup, startup mutation, uninstall, installation, Defender scan, forced restart or silent elevation is executed.

| Capability | Available now | Queued next / required gate |
| --- | --- | --- |
| Cleanup preview | Supported temp roots, exact observed paths/logical bytes/categories/errors, persistent selected file/folder exclusions. Unreadable exclusion settings block discovery; changed preferences invalidate previews. | Individually selected candidate actions only after a fresh exact-change preview, file-identity/reparse/activity revalidation and explicit confirmation. Protect user data, credentials, saves, settings and shared dependencies. Explain irreversible deletion and backups; restore points do not recover deleted files. |
| Startup management | Existing read-only HKCU/HKLM Run/RunOnce and Startup-folder inventory with source/coverage/unknown state. | Reversible selected enable/disable: show exact source/entry, current and intended values, permissions, backup/restore path and changed-since-preview check. No bulk toggles, silent elevation or running discovered commands. |
| Installed apps / uninstall | Bounded ARP registration metadata, source, version, publisher, local install location if validated, and registered mechanism hints. No raw uninstall command is read/executed. NoRemove restrictions are honored. | Select one app; validate its supported registered uninstaller or Windows Installer mechanism and show identity, requested operation, privilege/prompts and exact intended change before launch. Use supported Windows mechanisms; never force-delete application folders, bypass NoRemove, use Win32_Product or silently remove shared dependencies. |
| Disk space map | User-selected local fixed folder, known logical bytes, original treemap and linked list, exact inspection, snapshot drill/up/reset and partial/error reporting. | Broader drive analysis, physical allocation/hardlink-aware totals and validated refresh workflows. No performance, repair, safe-delete or complete-coverage claim without evidence. |
| Post-uninstall candidate review | Explicit complete baseline and later complete registration refresh, in memory for this session. Probe only prior recorded local install directories; surface evidence, unknowns and shared/user/system cautions. | Richer file-level ownership evidence after supported selected uninstall. Any later action must show exact candidate paths and consequences with user selection; never auto-remove shared dependencies, user data, saves or settings. No name-match AppData/profile sweep or “proven junk” label. |
| Duplicate-file review (later module) | **Queued, not implemented.** No content scan is added to ordinary inventory. | [F1 selected-folder full-content verification; F2 later manual reviewed actions](FILE-REVIEW-ROADMAP.md). Names alone are not evidence. Show exact paths/sizes, account for same-file hard links/reparse points, exclude protected/system/application roots by default, and preserve at least one independently verified copy. No automatic removal. |
| Broken-shortcut review (later module) | **Queued, not implemented.** No shortcut is resolved, launched or deleted by this update. | [S1 reasoned read-only target availability; S2 selected obsolete-shortcut removal](FILE-REVIEW-ROADMAP.md). Offline/network/temporary/inaccessible targets stay unknown, not confirmed broken. Revalidate exact selected shortcut paths; actions never affect the target application/data. |
| Windows Diagnostics (later module) | **Not implemented in phase one.** The in-app queue records this planned module; ordinary inventory runs no diagnostic/repair commands. | Ship [D1 evidence-based health and recurring crash/error summary, D2 explicit non-repair corruption checks, D3 guided selected repairs](WINDOWS-DIAGNOSTICS.md). Each finding needs source, time range, coverage, uncertainty and impact. Use current Microsoft semantics; explicit selection/elevation, safe cancellation/status and actual result logs precede repairs. No health scores, arbitrary DLL downloads or performance promises. |
| BIOS / Firmware | [Read-only CIM PC/board/BIOS identity, separately classified Windows Update firmware offers and narrowly verified generic official guidance](FIRMWARE-UPDATES.md). Available BIOS versions/model match remain Unknown; no flashing. | Exact OEM model/SKU or retail board/revision official adapters, vendor-specific comparison/release notes/prerequisites and last-check evidence. No retail substitution for OEM PCs, third-party BIOS assets, silent installs or forced restarts. Initial guidance is links only. |
| Hardware Upgrades (later tab) | **Queued, not implemented.** BIOS identity is firmware-reported, not a compatibility engine. | [H1 read-only inventory, H2 exact-model official specifications, H3 budget/use-case advice](HARDWARE-UPGRADES.md). Distinguish detected/manufacturer-verified/manual facts. Never infer PSU/connectors, clearance, free physical slots or soldered-memory upgradeability. No purchases or BIOS updates authorized. |
| Defender and updates | Existing read-only status/history, app/Windows/driver offers, and user-controlled MadClean release status/reminder. | User-initiated scans and individually selected installs after an explicit operation/source/permission preview. No new antivirus-engine claim, bulk driver replacement, silent self-install or forced restart. |

This queue is also visible in the app. It records capability scope and review conditions, not a schedule or implemented action. No external issue, reminder, scheduled task or client-PC action was created.
