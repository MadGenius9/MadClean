## Validation channel

The normal build job keeps repository contents read-only. A separate disposable Windows job will render genuine WPF client content and exercise test-owned native fixtures plus minimized Event Log queries. A separate trusted publisher job alone has contents-write permission, restricted to this repository's foundation branch on push/manual events. It publishes bounded source/run-bound reports and selected hashed PNGs to the private `madclean-verification` branch, so evidence is readable through Git when the REST API is blocked. It never force-pushes or exports arbitrary runner/user files. Successful compilation or a missing report is not a Windows validation pass.

All still-blocked stages remain visible; no unsupported capability is marked finished to clear this table. See CAPABILITIES.md, FILE-REVIEW-ROADMAP.md, WINDOWS-DIAGNOSTICS.md, HARDWARE-UPGRADES.md and HARDWARE-SOURCES.md for the detailed contracts.
