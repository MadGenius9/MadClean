## Private evidence channel

Build/native jobs have read-only repository contents permission. Only the trusted publisher job can write the dedicated private `madclean-verification` branch, restricted to this repository's feature-branch push/manual events. It validates artifact download integrity, source/run/attempt, bounded fixed reports, PNG hashes/chunks and complete test accounting before exporting fixed filenames. Compiler/test text is bounded and scrubbed before upload and again before excerpt publication; no production inventory or arbitrary runner files are exported. There are no force pushes. Missing reports, exit codes alone and successful compilation cannot become runtime passes.
